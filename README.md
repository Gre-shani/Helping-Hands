# Helping Hands

A Next.js frontend application for a donation and volunteer coordination platform using Shadcn UI.

## Features

- Role-based dashboards for:
  - Children's Homes
  - Donors
  - Service Providers
  - Delivery Volunteers
  - Admin

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

- `src/app/` - Next.js app directory
- `src/components/` - Reusable components
- `src/lib/` - Utility functions

## Technologies

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Shadcn UI
